# Mauli Events & Decorations website

## Run locally
1. Keep `index.html`, `style.css`, `script.js`, and the `images` folder together.
2. Open `index.html` in a browser, or use VS Code Live Server for local testing.
3. Do not move image files out of `images/`; the page references them with relative paths.

## Before publishing
- Confirm the phone number, owner name, service area and Instagram account with the client.
- Confirm prices and booking terms before adding them; no fixed prices are claimed on this site.
- Test WhatsApp, phone and Instagram links on mobile.
- For hosting, upload the complete contents of this folder to Netlify, GitHub Pages, or the client's hosting provider.
